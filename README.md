# X-Ray Classification using Deep Learning

This project focuses on **classifying chest X-ray images** using deep learning techniques to detect diseases such as **Tuberculosis / Pneumonia / Normal cases** (based on dataset used).

The goal is to assist in **medical image analysis** by building an accurate and efficient image classification model.

---

## 📌 Project Overview

- Domain: **Medical Imaging**
- Task: **Image Classification**
- Input: Chest X-ray images
- Output: Disease category (e.g., Normal / Infected)
- Approach: **Convolutional Neural Network (CNN)** / Deep Learning

---

## 🧠 Model & Techniques Used

- Convolutional Neural Networks (CNN)
- Image preprocessing & augmentation
- Train / Validation / Test split
- Performance evaluation using accuracy and loss
